# Quiz-first landing pass

This branch simplifies the consumer landing page around the Money Pattern Quiz.

Changes:
- Quiz-first hero and primary CTA
- Keeps the strongest recognition questions near the top
- Removes six archetype cards, investor architecture, and audience-heavy sections from the core consumer story
- Adds one clearly labeled example result instead of exposing all archetypes
- Compresses the product explanation to Financial Picture → Moment → Blueprint → Run
- Adds contextual-knowledge positioning
- Adds a lightweight `quiz_start_click` analytics hook when PostHog is available

The archetypes are framed as different money patterns, not levels or a hierarchy.
